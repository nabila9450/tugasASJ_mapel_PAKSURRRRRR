Pengertian VirtualBox

Ciri-ciri VirtualBox

Hypervisor Type 2 Dikembangkan Oracle Gratis Open-source Banyak OS dalam 1 komputer OS utama tidak terganggu

VirtualBox adalah perangkat lunak virtualisasi (Hypervisor Type 2) berlisensi open-source yang dikembangkan oleh Oracle. Software ini memungkinkan sebuah komputer fisik (Host OS) menjalankan satu atau beberapa sistem operasi virtual (Guest OS), seperti Linux Debian, Windows, atau macOS, secara bersamaan dalam lingkungan yang terisolasi tanpa memengaruhi sistem operasi utama.

Materi 2

Cara Install VirtualBox & Debian

1

Instalasi VirtualBox pada Komputer Host

  • Unduh installer VirtualBox resmi dari situs virtualbox.org.
  • Jalankan file setup installer (.exe di Windows / .dmg di Mac).
  • Ikuti wizard dengan menekan Next sampai proses penyalinan komponen selesai, lalu klik Finish.
2

Persiapan ISO Debian

  • Unduh file citra sistem Debian berformat .iso resmi dari debian.org (pilih edisi DVD / NetInst).
3

Membuat Mesin Virtual (VM) Baru

  • Buka VirtualBox, lalu klik tombol New.
  • Isi nama mesin (contoh: Debian-ASJ), pilih lokasi penyimpanan, dan masukkan file ISO Debian.
  • Alokasikan RAM (minimal 1024 MB / 2048 MB) dan jumlah core CPU (minimal 1 vCPU).
  • Buat media penyimpanan Virtual Hard Disk (VDI) minimal 10 GB – 20 GB, lalu klik Finish.
4

Instalasi OS Debian pada Mesin Virtual

  • Pilih mesin virtual yang telah dibuat, lalu klik Start.
  • Pada menu boot pembuka, pilih Graphical Install atau Install.
  • Pilih bahasa, negara, dan tata letak keyboard.
  • Isi hostname, domain, serta password untuk akun root dan akun user biasa.
  • Pada alur partisi disk, pilih Guided - use entire disk agar partisi dibagi otomatis.
  • Tunggu pemasangan paket sistem dasar, lalu pilih perangkat lunak tambahan (Desktop Environment atau Standard System Utilities).
  • Pasang GRUB bootloader pada hard disk utama (/dev/sda).
  • Klik Continue saat instalasi selesai untuk reboot pertama kali ke Debian.

Materi 3

Fungsi Perintah Terminal

Materi Praktikum ASJ penjelasan rinci setiap baris perintah terminal Linux yang digunakan dalam praktikum pembuatan dan pengelolaan direktori serta file.

1. Hak Akses Administrator

su Switch User

Fungsi: Memindahkan sesi pengguna aktif ke akun superuser/administrator (root) agar bisa menjalankan perintah tingkat sistem dengan wewenang penuh tanpa terhalang pembatasan izin (permission).

2. Pembuatan & Penghapusan Direktori

mkdir nama_folder Make Directory

Fungsi: Membuat satu direktori/folder baru di lokasi direktori aktif.

mkdir -p path/folder/sub_folder Make Directory - Parents

Fungsi: Membuat rantai direktori bertingkat otomatis dalam satu baris. Opsi -p membuat folder induk yang belum ada tanpa error.

rmdir nama_folder Remove Directory

Fungsi: Menghapus direktori yang kondisinya sepenuhnya kosong (tanpa file atau sub-folder).

rm -rf nama_folder Remove Recursive Force

Fungsi: Menghapus direktori beserta seluruh isi file dan sub-folder di dalamnya secara permanen dan paksa.

3. Navigasi & Orientasi Direktori

pwd Print Working Directory

Fungsi: Menampilkan path lengkap lokasi direktori yang sedang dibuka terminal.

cd nama_folder Change Directory

Fungsi: Memindahkan sesi terminal masuk ke direktori target.

cd .. Naik satu tingkat

Fungsi: Memindahkan posisi terminal keluar menuju direktori induk (parent directory).

ls List

Fungsi: Menampilkan daftar file dan folder di dalam direktori aktif.

ls -R List Recursive

Fungsi: Menampilkan struktur isi direktori beserta seluruh sub-folder secara terperinci dan bertingkat.

4. Pembuatan & Pengeditan File

touch path/ke/file.txt Buat file kosong

Fungsi: Membuat file baru kosong (0 byte) pada path yang ditentukan, atau memperbarui timestamp jika file sudah ada.

nano path/ke/file.txt Teks editor Nano

Fungsi: Membuka editor Nano di terminal untuk membuat, membaca, atau mengedit isi teks file target.

5. Pintasan Keyboard & Navigasi Nano

Ctrl + X Exit

Fungsi: Keluar dari program teks editor Nano.

Y Yes

Fungsi: Mengonfirmasi bahwa perubahan teks di Nano ingin disimpan (Save modified buffer).

N No

Fungsi: Menolak penyimpanan perubahan dan keluar dari Nano tanpa mengubah isi file asli.

Enter Tombol eksekusi

Fungsi: Mengonfirmasi nama file pada Nano, serta mengeksekusi baris perintah yang diketik di terminal Linux.

Contoh alur di terminal Debian
# masuk sebagai root
$ su
# buat folder bertingkat sekaligus
# mkdir -p /home/asj/praktikum/data
# pindah ke folder tujuan
# cd /home/asj/praktikum/data
# buat file kosong, lalu isi dengan nano
# touch catatan.txt
# nano catatan.txt
# simpan: Ctrl + X, lalu Y, lalu Enter

Materi 4

Hak Akses File & Direktori di Debian

Bagaimana cara dan konsep pembuatan/pengaturan hak akses (permissions) pada file dan direktori di Debian, mulai dari konsep dasar sampai perintah chmod dan chown.

Konsep Dasar Hak Akses di Linux Debian

Setiap file dan folder di Debian memiliki sistem keamanan yang dibagi menjadi 3 kategori pengguna dan 3 jenis hak akses.

1. Kategori Pengguna (Users)

u
User / OwnerPemilik asli yang membuat file/folder tersebut.
g
GroupSekumpulan user yang berada dalam satu kelompok/grup yang sama.
o
OthersPengguna umum / publik di luar pemilik dan grup.

2. Jenis Hak Akses (Permissions)

r
ReadMembaca isi file atau melihat daftar isi folder.
= 4
w
WriteMenulis, mengubah, menambah, atau menghapus isi file/folder.
= 2
x
ExecuteMengeksekusi file program atau membuka/masuk ke dalam direktori (folder).
= 1

Cara Membuat / Mengatur Hak Akses dengan chmod

Perintah chmod (Change Mode) digunakan untuk mengubah hak akses suatu file atau direktori. Coba kalkulator di bawah, centang kotaknya dan lihat angka serta perintahnya berubah.

r · 4w · 2x · 1 User (u) Group (g) Others (o)
Contoh cepat:
755
rwxr-xr-x
chmod 755 nama_file

Metode 1: Menggunakan Angka (Numeric / Oktal)

Jumlahkan nilai r (4), w (2), dan x (1) untuk masing-masing kategori (User - Group - Others).

Rumuschmod [angka_user][angka_group][angka_others] nama_file_atau_folder
chmod 755 tugas_asjFolder umum
Userrwx7 = 4+2+1
Grouprwx5 = 4+0+1
Othersrwx5 = 4+0+1

Fungsi: Mengatur hak akses folder tugas_asj: User mendapat nilai 7 (Baca, Tulis, Masuk), Group nilai 5 (Baca & Masuk), dan Others nilai 5 (Baca & Masuk). Biasanya digunakan untuk folder/direktori umum.

chmod 644 catatan.txtFile teks / dokumen
Userrwx6 = 4+2
Grouprwx4
Othersrwx4

Fungsi: Mengatur hak akses file catatan.txt: User mendapat nilai 6 (Baca & Tulis), sedangkan Group dan Others mendapat nilai 4 (hanya bisa Baca). Biasanya digunakan untuk file teks/dokumen.

chmod 777 tugas_asjAkses penuh untuk semua
Userrwx7
Grouprwx7
Othersrwx7

Fungsi: Memberikan akses penuh (Baca, Tulis, Masuk) kepada siapa saja tanpa batasan (User, Group, Others semuanya bernilai 7).

Metode 2: Menggunakan Simbol (Symbolic Mode)

Tambahkan (+) atau kurangi (−) hak akses secara spesifik tanpa harus menghitung angka.

Rumuschmod [kategori][operator][izin] nama_file_atau_folder
chmod u+x skrip.shTambah hak execute
u+ xpemilik

Fungsi: Menambahkan (+) hak execute (x) khusus untuk pemilik (user / u) pada file skrip.sh agar bisa dijalankan sebagai program.

chmod o-rw dokumen.txtCabut hak baca & tulis
o− r wpengguna lain

Fungsi: Mencabut (-) hak baca dan tulis (r dan w) dari pengguna lain (others / o) pada file dokumen.txt demi keamanan.

chmod a+r catatan.txtBeri hak baca ke semua
a+ rsemua orang

Fungsi: Memberikan (+) hak baca (r) kepada semua orang (all / a) pada file catatan.txt.

Pengaturan Menyeluruh (Rekursif) & Kepemilikan

Ketika membuat folder bercabang yang berisi banyak file di dalamnya, diperlukan perintah tambahan agar hak akses berubah secara serentak.

chmod -R 755 tugas_asjRecursive
tugas_asj/└ sub_folder/   └ file.txt

Fungsi: Mengubah hak akses folder tugas_asj beserta seluruh isi sub-folder dan file di dalamnya secara otomatis sekaligus, tanpa harus mengubahnya satu per satu.

chown -R root:root tugas_asjChange Owner
ownerrootgrouproot

Fungsi: Mengubah kepemilikan (owner dan group) dari folder tugas_asj dan seluruh isinya agar dikuasai sepenuhnya oleh user bernama root (atau bisa diganti dengan nama user Anda). Berguna untuk menghindari masalah Permission Denied saat user biasa ingin memodifikasi file sistem.

Penutup

Kesimpulan

Penggunaan VirtualBox menyediakan lingkungan simulasi yang aman bagi calon Network Administrator untuk mempelajari dan mengonfigurasi sistem operasi Linux Debian tanpa risiko merusak sistem operasi utama pada komputer fisik.

Penguasaan perintah dasar terminal seperti navigasi (cd, pwd), manajemen direktori (mkdir -p, rmdir), serta pengelolaan file (touch, nano) adalah fondasi utama mata pelajaran Administrasi Sistem Jaringan (ASJ). Struktur perintah ini memungkinkan administrator membangun, mengatur hak akses, dan mengorganisasi direktori kerja sistem secara terstruktur dan efisien.
